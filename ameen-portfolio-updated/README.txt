=======================================

DESIGN
- Cream / red / orange visual identity and editorial layout retained.
- Content highlights Ameen's computer science studies, skills, projects, achievements, and goals.

FILES
- index.html  : page structure, SEO/social metadata, accessible project detail dialog
- style.css   : original styles plus responsive and interaction refinements
- script.js   : navigation, scroll progress, reveal effects, project dialog, and contact form

NEW IMPROVEMENTS
- Accessible skip link and keyboard focus styles
- Scroll progress indicator
- Improved mobile menu behavior and Escape-key handling
- Project detail modal for the three selected project cards
- Reduced-motion support and safe fallback when IntersectionObserver is unavailable

- Better form validation and clearer mail-app feedback

HOW TO RUN
1. Keep index.html, style.css, and script.js in the same folder.
2. Keep new-portrait-cutout.png beside index.html; the home section uses this transparent portrait.
3. Open index.html in a browser, or use VS Code Live Server.

BEFORE PUBLISHING — IMPORTANT
- Replace both portrait images together if you want to use a different portrait.
- Confirm education, GPA, achievements, and project details before publishing.
- Add direct repository links when available; the current GitHub links point to the profile.
- Confirm the contact email and social profile URLs in index.html and script.js.
- The contact form uses mailto: and does not store or submit messages to a server. For server-side submissions, connect a form backend.
- Google Fonts and Lucide icons load from external CDNs.
